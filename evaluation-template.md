# Evidence Checklist

Before finalizing an evaluation, verify:

* [ ] The issue is visibly supported by the video.
* [ ] The correct object or subject is identified.
* [ ] The relevant segment or timestamp is recorded.
* [ ] The issue is assigned to the most appropriate category.
* [ ] Severity reflects the actual impact of the issue.
* [ ] No unsupported assumptions are included.
* [ ] Similar issues are grouped appropriately.
* [ ] The description explains both the observation and its impact.
* [ ] Events are evaluated in their correct temporal order.
* [ ] The final assessment reflects the overall video rather than one isolated frame.

---

# Category Distinction Guide

| Category              | Primary Question                                                    |
| --------------------- | ------------------------------------------------------------------- |
| Visual Quality        | Does the video look visually clean and technically coherent?        |
| Prompt Alignment      | Does the video accurately follow the requested scenario?            |
| Physical Plausibility | Do objects, people, and interactions behave realistically?          |
| Motion Quality        | Does movement appear smooth and natural?                            |
| Temporal Consistency  | Do objects, subjects, and scene states remain consistent over time? |

## Evaluation Principle

Only report issues that can be supported by observable evidence.

A strong evaluation should be:

**Accurate → Specific → Evidence-based → Consistent → Reproducible**
